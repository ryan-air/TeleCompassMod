# TeleCompassMod
Tele Compass is a custom mod that introduces a new programmable teleportation item allowing players to save, manage, and return to multiple spatial checkpoints across dimensions. Mod is designed with a strong emphasis on clean java architecture, data persistence, and event-driven gameplay systems. 

My first mod, coding something new everyday!

Refer to the "telecompass-1.0.0.jar" file to play with this feature in game!
